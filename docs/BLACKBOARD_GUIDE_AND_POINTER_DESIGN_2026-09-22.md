## §1 一句话设计

给模型两样东西：**去哪儿读**（黑板 `guide` 说明书分区，pull 面）和**怎么回查**（机械定位符 ＋ 有界回查面）。
两项都**不改变任何现有机制的语义**、**不新增自动注入**、**不占用 pull-delta 头段预算**。

## §2 问题（现场读数，非推断）

1. **机制没有说明书 ⇒ 模型判断偏差**：0bg 轮把「调用级 Job 连坐回收」误判为「缓冲/句柄行为」（§5 g）、把软档 256K／288K 误标成「硬提醒 2 次」（§5 a）、把 `rounds_since_last_compaction=0` 的成因（浅压 14 %）当成读法问题。三处都不是能力问题，是**没人告诉它机制长什么样**。
2. **压缩后不可定位 ⇒ 重建成本**：本轮 7 次压缩、触发 208–298K、压后 178–231K；较早内容只剩摘要。模型为对抗压缩自写 **8 次黑板笔记／5 次 `orientation_checkpoint`／8 次 `plan_write`** —— 重建成本真实存在且可被机械替代一部分。
3. **头段预算已经很紧**：真机实测 **17 条提醒只有 4 次到达模型**（头段被水位标＋徽章占去 189–216 B，余量 40–42 B）。⇒ 本设计**任何新面都不得再挤头段**。

## §3 设计 A：黑板说明书分区（`section=guide`）

### 3.1 形态

- 黑板新增分区 `guide`（渲染面 ＋ selector 折叠面），内容**静态**：revision 不随轮次变化 ⇒ pull-delta **delta 恒 0 ⇒ 不产生头段徽章**。
- **pull 面**：不自动注入、不随轮推送，模型需要时自行 `blackboard_read section=guide`（与 `rli`／`temporal` 面同格）。
- 与 0bh ① 的分工：① 给**提醒**争独立预算；本项**一分头段预算都不占**。

### 3.2 内容（四类，简单明了）

| 类 | 内容 | 目的 |
|---|---|---|
| **职责图** | 谁在管什么：压缩（模型自选／H1-T1 硬线／机械不兜底）／RLI（只给特征、不给动作建议）／LIF（现役计数＋机械连带记录）／黑板（不受窗口影响）／机械审查（`mechanical_audit_update` 各类 key）／资源 Job（调用级拆树、run 级上限） | 消除"这是谁在动我"的误判 |
| **术语表** | RLI 缩写族（`λ̂／T̂／u／θ／ρ／c／p1／pred`）＋机械码固定释义（`context_scale:<档>`／`host_resource_denied`／`reclaim_performed` 等） | 与面头符号表同源，压缩后仍可查 |
| **常见误解** | ① 提醒只是读数、**不含动作建议**；② 调用内拉起的**后代随调用一并关闭**（要长活走工具自带后台）；③ 压缩是**模型自选**、机械层不做兜底；④ 域迁移**只报确认式**（即时计数走机械记录） | 直接对应本轮实测的三处误判 |
| **回查入口** | 定位符语法与用法（见 §4）＋ 各 `blackboard_read` 分区/selector 一览 | 让"我丢了什么、去哪儿找"有答案 |

### 3.3 单源、版本与钉子

- 正文由**常量单一源**生成（与工具描述常量、面头符号表同源，沿用 FR-5 纪律），并随面携带 `digest`（内容 hash）。
- 钉子：断言 `guide` 文本与常量逐项一致；常量改动而 `guide` 未同步 ⇒ 测试红（防漂移）。
- 边界：**只释机制，不给动作建议**（0bf 纪律）；不写实施流水、不写提交号。

### 3.4 预算

`guide` 面自身 **≤1 KiB**（与 `temporal`／`rli` 面同格）；折叠 selector 供深读；**不进 pull-delta 段**。

## §4 设计 B：机械定位符与有界回查面

### 4.1 指针语法

定位符＝**可复制、可回查的短坐标**（不是 URL）：`r<轮>·b<块>·s<seq>`，其中 `r`＝决策轮号、`b`＝压缩块号、`s`＝journal `seq`（`seq` 即事件行号）；必要时追加内容锚 `#<sha 前缀 8>`。

示例：`r112·b7·s1841#9d3ef5b2`（第 112 轮／第 7 块／journal 第 1841 号事件／内容 sha 前缀）。

### 4.2 生成点（三处，与门二「导航形式」同一套语法）

1. **压缩回执**：折了哪些块 ＋ 每块指针 ＋ 被折轮次区间（即门二裁定的「较早内容仅留导航形式」——**保留域位置与轮号、不保留正文**）。
2. **域时间线**：每段一行指针（域＋轮号）。
3. **压缩块表**：块号 ↔ 指针。

> 一致性要求：**导航形式与定位符是同一套坐标**，不得出现两套（模型不应学两遍）。

### 4.3 回查面（有界）

- 新增 `blackboard_read section=journal anchor=<ptr>`：机械定位到对应事件，**只回该事件的机械字段摘要（≤512 B）＋指针回显**，不整行灌 journal（一行 payload 可能数 KB）。
- 文件内容仍走 `read_file`（`offset`/`limit` ＋ `sha256` 锚点）；指针内 `#sha` 用于内容一致性判定。

### 4.4 正反两面均有回应（用户令：必须）

| 情形 | 机械回应 |
|---|---|
| **命中** | 该事件机械字段摘要（≤512 B）＋指针回显＋`seq` 与时间读数 |
| **指针不存在**（格式错／`seq` 越界） | 明确文本：`指针不存在：…（本 run 事件数 N）` |
| **指向的事件不在本 run**（跨 run／已归档未收录） | 明确文本：`该指针属于其他 run 或已归档：…` |
| **内容已变**（`#sha` 不符） | 明确文本：`指针已过期：内容 sha 与指针不符（当前 …）` |

**禁止静默空**：任何未命中都必须有文本回应（沿 O4 先例：渲染层错误文本 + `exit_code 0`，但**不得**返回空串）。

### 4.5 预算

指针 ≤**24 B/条**；单次回查 ≤**512 B**；**指针预算单列**，不与 0bh ③ 的 240 B 注解预算互挤。

## §5 判据（可机械核，五条）

1. **不占头段**：长会话内多次读 `guide`，pull-delta 头字节数**不变**（无新徽章）。
2. **单一源**：`guide` 文本与常量逐项一致（漂移测试）。
3. **正例**：任一指针经 `anchor=` 可取回对应事件摘要（真机轮内实测，落 journal 读数）。
4. **反例**：三类未命中各有明确告知文本，**零静默空**。
5. **预算与不反噬**：指针＋回查字节进读数面；同轮提醒投递率不因本项下降（与 0bh ① 同轮读数对照）。

## §6 落点与批序

S1 勘定（面形态与指针语法定稿）→ S2 落码（面渲染＋回查面＋钉子）→ S3 真机（`guide` 读取次数／定位符使用率／回查成功率／反例覆盖）→ S4 收口（含读数进报告）。**前置＝0.6.10 重建**（0bg 码需先进载体）。

## §7 不做与风险

- **不做**：不给动作建议；不改压缩语义（门二＝只做目标档告知）；不新增自动注入；不把 `guide` 做成每轮提示；不引入 URL/超链接形态（模型面是文本，定位符足够）。
- **风险①：说明书漂移** → 单源＋`digest`＋钉子。
- **风险②：定位符变成新的 token 陷阱** → 回查有界（≤512 B）＋只回机械摘要＋指针 ≤24 B。
- **风险③：新面挤占提醒预算** → `guide` 不挂徽章、指针预算单列，并由判据 1／5 把关。
