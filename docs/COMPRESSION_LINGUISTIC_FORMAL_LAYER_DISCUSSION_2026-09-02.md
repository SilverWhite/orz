## 1. 现状盘点：机械压缩的内容与缺口

现状（`implemented`，零模型调用）：

- 触发：160K 普通 / 200K 兜底 / 384K 有效窗口；摘要冷却 ≥2 模型轮；缩减守卫
  `min_compactable`=5K、缩减门 40%。
- 产物：五段模板摘要（目的 3K / 计划 3K / 变动文件路径 5K·Top-40 / 注意事项 3K /
  后续衔接 3K 固定中性占位；合计 17K）+ 滚动单 marker + `.gsa/compaction/` 存档。
- 注意事项槽 = HA 结构化事实聚合：plan 失败/阻塞步骤 + 最近 5 条 exec 错误（单条
  ≈200 字符截断）+ 最近 3 条动作失败 receipt。
- 事件：`context_compressed.mode=mechanical`；摘要链不继承语义（每次全新产物）。

缺口（本次讨论对象）：

1. **无「概括」**：同一失败目标反复失败 vs 不同错误，信息密度相同——F4 失败目标身份
   已入事件面（kind + digest + ≤80B preview），但未进压缩聚合；聚合项应保留计数 +
   错误码 + 首末发生时间（同一 digest 的多次失败合并为一行，行内错误码集合区分
   失败模式；压缩不携带日志级明细）。
2. **无「前瞻中心」**：摘要不保证保留后续动作仍会引用的实体/锚点（依赖图 read→write
   锚点边 + 工具→实体变更边已实施 2026-09-01，未接入压缩）。
3. **无「关系保真」**：使能/因果关系（receipt、失败原因、下一步前提）与详述混在同一
   截断里，删除粒度与关系类型无关。
4. **错误事实跨 marker 重复**（同一 plan epoch 多次压缩），且缺时间线（试过什么、按
   什么顺序、处于什么域）。

## 2. 语言学形式层 → 机械特征映射（确定性、零模型）

只借用语言学的**形式/结构层**，不借用语义理解；每条都落到事件流/依赖图/digest 可
机械计算的特征：

| 语言学概念 | 形式内容（确定性） | 机械落点 | 状态 |
|---|---|---|---|
| 宏规则（van Dijk & Kintsch）：删除 / 概括 / 建构 | 删除=落盘内容只留指针；概括=同类重复合成；建构=循环归约成一步 | 删除=既有指针机制；概括=失败目标聚合（F4 身份 (kind,id) + 计数 + 错误码集合 + 首末发生时间 + 目标 preview ≤80B）；建构=动作转移模式归约 | 删除已实施；概括/建构未实施 |
| Centering Theory（前瞻中心） | 后续话语要引用的实体集合必须保留 | 开放锚点（依赖图 read→write 边）+ 最近 read 实体 + 失败目标身份 | 依赖图已实施，未接入压缩 |
| RST 核心/卫星 | 保留使能/因果/结果关系，删详述/背景 | receipt↔事件链同构、失败原因保留、长输出裁剪 | 事件链 verifier 已建；未做关系级选择 |
| register（SFL 语场/语旨/语式） | 摘要须保持语场（任务）、语旨（压力）、语式（通道）完整 | 五段槽系统化 = 每槽「必须保什么」的检查清单 | 五段槽已是原型，未系统化 |
| 语篇段落结构（discourse segmentation / episode） | 话语按段标注并保持时序，不排名、不加权重 | 聚合事实按行键 (kind,id) 组织 + 行内域序列标注（如 `normal(r10–12)→pressure(r13–15)`）+ 按首末时间排列 | 未实施 |

不引入：生成式摘要（两次裁决否决：2026-08-08 零模型摘要、v1.29 撤销 LLM 摘要调用）、
语义匹配/嵌入相似度（非确定性、需模型）、DRT 等重推理形式化（marker + recent tail +
指针已有对应物）。

## 3. 域作为压缩参考（草案）

定位：**域变化不触发压缩**；压缩发生时（token 节奏），域仅作为**内容标注与排列**的
参考——纯结构变换，不做加权、不给优先级、不改变保留集合。

- 标注与排列：压缩产物中的聚合事实（失败目标链等）按行键 (kind, id) 组织、按首末
  发生时间排列，域以行内序列标注（如 `normal(r10–12)→pressure(r13–15)`）；只增加
  信息结构，不增加判断。
- 聚合口径（2026-09-02 用户裁决，含修订）：
  - 行键 = F4 失败目标身份 (kind, id)；计数按事件：行键内失败事件逐次累加（同一
    目标失败 N 次计 N，一行内计 N）。**修订（2026-09-02）**：不再按日志分行——F4
    身份字段只有命令 digest + preview，无失败日志摘要；压缩不携带日志级明细，不
    为此引入日志摘要口径。
  - 错误码：行内集合（含各码计数，如 `[timeout×3, deny×2]`；错误码取自事件结构化
    Fail.code，非日志内容）；要么不留、要么全留，无中间档——全留=集合成员不截断；
    不留=模型自行回查日志；禁止静默丢码。实际受注意事项槽 3K 上限约束，超限走既有
    「显式截断 + 指针」纪律（报告其余 N 个错误码见存档），不属误导。**审查修正
    （2026-09-02）**：`failure_agg` 不是 `blackboard_read` 查询分区，被 3K 槽挤出
    的聚合行普通回查取不到——被挤出行随压缩摘要存档以「失败目标聚合（3K 溢出
    补全）」段保存，指针据此保持可回查（实现见 CONTEXT_COMPACTION_DESIGN
    §4.4.4 / 审查记录）。**错误码可复核口径（2026-09-02 登记）**：host 工具错误
    的 `tool_completed.error` 是自由文本，`tool_timeout`/`tool_not_found`/
    `execution_failed` 由 ToolErrorKind 结构化映射产生（非日志解析）但事件载荷
    不含该结构化 code（锚点/候选拒单路径的 `error` 字段即结构化 code）；§5 离线
    verifier 须复刻同一映射（或经独立 schema-first 切片给 host 错误事件补结构化
    code 字段后直读），不得从 error 文本推导。
  - 首末时间：相对 run 起点墙钟秒（与 temporal `t` 同刻度；轮号是事件序列，不是
    根本时间）。
  - 域不参与行键（方案 A，2026-09-02 定案）：域降级为行内序列标注，如
    `normal(r10–12)→pressure(r13–15)`（含各段驻留与切换轮）。LIF 域是连续电位过阈
    的离散化，切换中间部分的轮标签带判定误差；行键不含域 ⇒ 中间部分被天然吸收，
    无需定位边界、无需处理边界误差。**修订（2026-09-02）**：原「跨域不合并」撤销
    ——同一目标跨域合并为带域序列的单行，时间轴与动作逻辑由行内序列 + 首末墙钟
    承载，不依赖行切分。
- 跨 marker 去重（2026-09-02 用户裁决：借聚合顺带解决）：行键即去重键 = (kind, id)，
  plan epoch 内累计，epoch 轮换时重置；旧 marker 内容被新聚合行吸收，滚动单 marker
  语义自然成立。
- 聚合状态归属（2026-09-02 用户裁决）：聚合状态归黑板——epoch 作用域、随黑板 plan
  epoch 轮换自然重置（重置机制随黑板既有轮换免费获得，无需独立机制）；具体分区归属
  （独立内部分区或并入既有分区）留正式设计定。
- 域标注 join 规则（2026-09-02 定案：写时盖章）：失败事件写入黑板聚合时，取该事件
  所属决策轮的域值盖章——temporal 域每决策轮重算一次，一轮内失败事件共享同域值，
  轮即 join 键、无歧义。行内维护域段书签：按盖章顺序归并——同域并入当前段、异域
  开新段记切换轮；段内轮/时间范围由段内事件首末时间给出，渲染如
  `normal(r10–12)→pressure(r13–15)`。不做渲染时回溯 join（黑板 live 内存无 epoch
  全量域序列：History 有界 ≤20、spikes 仅侧车归档）。边界：切换轮的失败标签=引擎
  当轮算出的值、可能带误差——接受（域仅行内标注，非行键，不产生行碎片）；start
  域照常盖章；写路径与 temporal 同属控制器/黑板，当轮域可达。**已知边界（2026-09-02
  审查登记）**：段轮区间 = 该目标在该域的失败事件首末轮（非域整体驻留区间；同域
  失败隔空跨过中间系统域切换会合并——保留时间轴近似，接受）；行内 t/轮号为 run
  作用域（run-relative LIF 原点），当前接线（CLI 新 plan_id 轮换清空 failure_agg、
  ACP 每 prompt 重建黑板且不挂 epoch 归档）不产生跨 run 混轴，恢复同 epoch 继续
  累计属未来切片（届时须带 run 轴或开新行）。
- 域切换频率（2026-09-02 回查 102 runs / 4157 决策轮）：
  - normal 90.8% / low_progress 5.3% / start 3.7% / pressure 0.1%（6 点）/ stuck 0；
    记录的迁移 median 2/run、mean 3.14、38% run 零迁移、max 20（迁移日志 ≤20 条
    有界）；每轮约 0.07 次切换——整体低频，**「域≈阶段而非事件类型」成立**。
  - 边界：low_progress 段 79% 仅 1 轮（avg 驻留 1.3 轮）——它是"进度停滞"的瞬态
    标记而非稳定阶段。方案 A 下 flicker 不再拆行：单轮瞬态段由行内域序列标注吸收，
    跨度由墙钟首末时间给出（**修订**：原「flicker 区拆行属预期（正是时间轴信息）」
    立场被方案 A 取代——拆行会把标签噪声编码成行结构）。
  - 跨域判定（2026-09-02 修订）：行键不含域 ⇒ 无需判定跨域是否合并；实际分组以
    normal 为主、lp 瞬态标记为辅，单轮 flicker 不再产生碎片行；行内域序列保留
    时间轴语义。
- 产物描述：域序列本身**不写入 marker**（维持纯 PULL）；temporal `recent(k)` 首行
  压缩摘要是域序列本身的唯一模型可见入口（2026-09-02 用户裁决：维持纯 PULL）；
  压缩产物中的逐行域标注属派生标注，随聚合行注入，不构成域序列写入 marker。
- 边界：temporal 分区零注入不变量维持；压缩产物仅对既有事实做标注/排列变换，不因
  域而增删事实。

## 4. 不变量与不做什么

- 触发、冷却、缩减守卫、17K、存档恒写入、marker 恒带 digest：全部不变。
- 零模型调用：一切新机制只消费结构化事件 / 依赖图 / digest。
- 不恢复 LLM/语义摘要；不给机械层加语义匹配。
- 注意事项槽保持「给事实不给建议」；后续衔接槽保持中性占位（主模型自行判断）。
- 不声明实际优化收益（用户边界 ④）：变更仅为结构合理性/完整性，收益评估不在范围。

## 5. 验证思路（离线、确定性、零模型）

- 复用 102 runs / 4157 决策点离线数据：对每个（虚拟）压缩点回放，计算「F4 失败目标
  聚合 + 开放锚点」对**压缩后仍会再次出现**的失败目标/实体的覆盖率，与现状「最近 5
  条截断错误」对比。
- 压缩点代理口径（2026-09-02 修订）：回放数据无逐轮 token 用量，不按真实 160K/200K
  规则复现压缩点；轮间隔粗代理即可——该值仅作初步判断，102 runs（迁移 median 2/run、
  38% 零迁移、low_progress 段 78% 单轮）已足够确立「域切换不频繁、按域标注碎片可控」
  的结构结论，不做 token 级复现。
- 「概括」正确性：同一 digest 计数与事件链中 `failure_target` 出现次数一致（digest
  可复核）；错误码集合/首末时间与事件载荷一致。
- 错误码可复核口径（2026-09-02 审查登记）：host 工具错误（ToolError）的
  `tool_completed.error` 为自由文本，聚合码来自 ToolErrorKind→code 映射（见 §3
  错误码 bullet）；离线 verifier 复刻同一映射核对，或先经独立 schema-first 切片
  为 host 错误事件补结构化 code 字段再直读——不得从 error 文本推导。
- 行内刻度边界（2026-09-02 审查登记）：聚合行 t/轮号为 run 作用域（同 temporal
  `t`）；跨 run 恢复同一 epoch 继续累计时行内刻度不可比（当前接线规避，见 §3
  域标注边界），离线回放按单 run 数据核对。
- 全部指标由事件链 verifier 扩展计算，不引入模型。
- 验证目标是结构正确性与充分性，不评估决策收益（见 §4 不声明收益）。
