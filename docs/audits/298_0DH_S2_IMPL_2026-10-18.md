## §1 五件落码（D1–D5/D6 全落）

1. **通道重开（D1）**：`orz-host/tools.rs` 生产装配 `run_terminal_cmd_tool_params()`
   显式注入 `"hide_background_input": false`（`BashParams` struct/serde 缺省 `true`
   **不动**——库层封闭是其他宿主安全缺省，orz 以装配注入受控重开）；
   `RETAINED_GROK_BUILD_TOOLS` **+2**（`get_task_output`、`kill_task`——`requires_expr`
   在 `enabled_background ∧ ¬hide_background_input` 时强制同台）；`allow_background_operator=false`
   维持（`&` 不开放，「一次调用＝一个结果」不动）。**8 工具面纪律第二显式例外（+2）**。
2. **收割豁除（D2）**：`ProcessTreeRecord` +`lifetime`（`"call"` serde 缺省／`"session"`，
   旧行零迁移）；`SpawnObservation` +`SpawnLifetime`；`ProcessGroup::attach_with_lifetime`
   （显式后台 shell 落 session 行，`handle_run_background` 传 `Session`）；xai-tty-utils
   新增**进程内会话标记集**（`mark_spawn_session`/`session_spawn_marks`，pid→attach 时钟）
   ——auto-bg/Ctrl+G 在 `transition_to_background` 转换时刻标记（其登记行已以 `call`
   落盘，标记为第二豁除源）；`plan_sweep` 增第六参 `session_spawns`，**Finalize 臂对
   `lifetime=="session"` 行或在册标记行（pid 匹配＋时钟容差同 `CREATION_TIME_TOLERANCE_MS`）
   `Refuse(SessionOwned)` 审计可见不杀**；Start sweep **不查标记**（宿主已死的 session
   行照扫＝0bq 孤儿兜底不动）；refusal 键 `session_owned`（无冻结消费面，已核实）。
3. **30h（D4）**：`DEFAULT_BG_MAX_RUNTIME` 36_000s→**108_000s**（actor 字段构造期解析）；
   env 口子 `GROK_BG_MAX_RUNTIME_MS`（**钳位下限 1h**、0/非法回落缺省——绝对兜底不可配没）；
   `ABSOLUTE_MAX_TIMEOUT_MS` 36_000_000→108_000_000（模型正向超时钳制同步）；
   monitor 工具常量不动（不在保留面）；idle-kill 300s 原样。
4. **增量读出（D6）**：`ProcessState` +`unserved`/`unserved_skipped`/`served_once`
   （256KB 帽、溢出丢最旧并计数、UTF-8 边界保留）；`GetTask` 改走
   `take_task_snapshot`——**首读＝既有全窗（游标钉定）／续读＝仅新增段（skip 如实报）
   ／终态读＝余段返回后封口**（封口后重复查询回落现役尾窗）；`TaskSnapshot`
   +`new_output_bytes`、`TaskOutputResult` +`new_bytes`（optional，`None`＝旧语义——
   等待/tombstone/前台）；渲染补一行 `New output: N bytes since the last read`；
   全量历史恒走 `read_file(output_file)`。
5. **教学面（D5）**：描述模板 `timeout: 0` 句改写（runs until it exits / kill /
   ~30h safety cap——S1 勘定结论三的文案兑现）；`is_background` schema 描述补会话域
   边界句；`BackgroundTaskStarted` summary 提取为 `background_started_summary`
   （跨 turn 存活／~30h／增量读出指引一行，just-in-time）；完成 reminder 现役零改动。
