# 313 批：远程形态第三轮澄清——台式机形态＋PIN 触发时机＋双秘密分离（2026-10-19）

> **批次性质**：裁决落账批（零源码零跑批；**计数 60 不变**；候选
> `OBS-REMOTE-ONE-TO-ONE-2026-10-19` 维持 `candidate`）。

> 进锁定也能触发」／「PIN虽然高权限但这是日常使用的码，隐私性不足」）。

## §1 三点澄清与修正（调研底稿 v1.3 §9）

1. **台式机形态修正**：§7-④「内置键盘不可拔＝逃生面」对台式**不成立**——台式全部
   输入外置，配对白名单登记的键盘/鼠标（实例 ID）**就是唯一逃生输入面**，白名单纪律
   不可豁免。装机基线检查 +2＝UEFI「USB 键盘支持」开启（否则 BitLocker pre-boot PIN
   无从输入）＋TPM 2.0 在位核验（BitLocker 已启用＝用户实测在案）。
2. **PIN 触发时机边界**：「进锁定也能触发」对**数据卷成立**（软锁不关机——重挂载须
   输密码，已在 312 软锁档）；**系统卷不成立**——BitLocker PIN 只在固件 pre-boot 门，
   运行中无 API 重锁 C:（312 硬边界不变），运行期锁＝锁屏＋orz 层 ACAF 密码门。两档
   划分不变：不关机的锁＝软锁＋锁屏＋fail-closed；要 BitLocker PIN 门＝必须重启。
3. **双秘密分离（修正 312 的「PIN＝ACAF 密码」）**：**ACAF 密码＝日常码**（高频暴露）；
   **BitLocker 启动 PIN＝独立低频秘密**（装机时设置一次、纯记忆不落盘——TPM+PIN 的
   PIN 部分本不存储）。恢复链＝物理在机前输启动 PIN 进系统 → 再输日常码解锁数据卷/
   远程。分离后日常码泄露也进不了启动门。装机基线 +1＝启动 PIN 独立设置环节（与
   ACAF 密码分两次输入）。
