## 1. tokenizer 纠正记录

376 初次落码时嵌入的是 `deepseek-ai/DeepSeek-V3/tokenizer.json`。用户指出当前
在役模型是 V4.1 后，已核对并替换：

| | DeepSeek-V3 | DeepSeek-V4.1-Flash |
|---|---|---|
| `tokenizer.json` | 7,847,652 B | 6,367,257 B |
| vocab | 129,280 | 128,000 |
| merges | — | 127,741 |
| 本项目状态 | 已删除 | **当前使用** |

- 资产：`orz/crates/orz-loop/assets/deepseek-v4.1-flash-tokenizer.json`
- 常量：`PROVIDER_TOKENIZER_NAME = "deepseek-v4.1-flash"`
- 绑定模型：`deepseek-flash`（transport 注释明确为 DeepSeek-V4.1-Flash）
- 结论：V3 tokenizer **不能**作为 V4.1 的精确预算依据；替换后 tokenizer 单测 2/2，
  loop 969/0/3、host 453/0/6（替换后重跑）。

**仍存在的边界**：模型与 tokenizer 的绑定目前靠代码/文档约束，没有自动一致性
检查；未来切到 V4-Pro 或其他 SKU 时必须同步替换 tokenizer，否则压缩预算会漂移。
计费仍以 DeepSeek 控制台为准。
