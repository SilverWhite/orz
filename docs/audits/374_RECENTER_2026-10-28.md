## §0 结论

`context_manage(mode=recenter)` 已落码：

- 返回 **state**（黑板 `state` 分区，固定 6 字段）＋**最近 5 个完整工具轮**的紧凑摘要＋显式 **next**。
- 只取完整轮（`tool_calls` 与 tool 结果配对）；半截轮不进入。
- 硬预算 **≤1K token（chars/2）**；超限优先截 recent，**next 保留**。
- 只读：不写会话/黑板/marker、不置压缩窗口、不落 `ContextCompressed`、不注入常驻文本。
- 仅 `mode=recenter` 本身；夹带 `summary/whitelist/handover/keep_recent_rounds` 整调用 exit 1。
- active decisions ≤5 属 M1.5（decisions 台账尚未落码），本批不读 `.gsa/decisions`。

## §1 输出形态

```text
[recenter v1] run=RUN-...
state:
state v1
goal: ...
now: ...
next: ...
open: ...
constraints: ...
updated: ...
recent:
r1 read_file src/a.rs -> 已读
r2 grep ... -> 命中 3 处
next: ...
```

`recent` 每轮一行：`rN tool target -> final_reply`；target ≤48 字符、reply ≤80 字符；多工具轮最多列 2 个工具，余下 `+N tools`。空 state 显示 `（无）`；无完整轮显示 `none`；无 next 显示 `next: none`。
