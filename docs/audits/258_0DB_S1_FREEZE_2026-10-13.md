## §5 runner 规格（S2 实现）

1. 读 manifest → 按域顺序迭代任务 → 题级台账去重（已完成题跳过）。
2. 每题调 `tau2 run --domain <d> --task-ids <id> --num-trials 4 --task-split-name base --save-to <轮目录>`（orz 臂则经适配器等价路径）。
3. 逐 sim 收取：轨迹 JSON 存在性＋reward 字段机械提取 → 追加模拟级 journal（append-only）。
4. 限流退避（429/5xx 指数退避＋抖动）；chunk 收口记账（tokens/RMB/限流次数）；进程级断点续跑（台账即状态）。
5. 对照臂＝同 runner 换 `tau2 run` 直连（不经适配器），airline 段复用。
