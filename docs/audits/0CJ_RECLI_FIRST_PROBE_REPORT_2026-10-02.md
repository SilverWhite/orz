## 3. RLI 与时间元认知判读（回答「消费为什么是 0」）

### 3.1 模型面实际的时间元认知来源（journal mechanical_audit 全量清单）

| 注入面 | 条数 | 内容与角色 |
|---|---|---|
| `budget` | **136** | 每工具批后注入「已用 N/999 轮」——**轮次进程感的主来源**（每批一刷新，无需任何拉取） |
| `tool_result` | 195 | 工具结果摘要行 |
| `lif_domain` | **109** | LIF 域迁移记录；模型面按 0bf ② 触发规则注入「新域稳定确认」（新域稳定 ≥3 轮一次性）——**域/节奏感来源** |
| `context_scale` | 11 | 上下文水位行 |
| `model_compression` | 6 | 模型参与压缩 marker（对应 `context_compressed` ×10） |
| `plan_write_guidance` | 1 | 初始轮三问（0x，post_tool_batch_gap 一次性） |

**结论**：模型的时间元认知由机械层**主动渲染**的 resident 行族（budget／temporal／域确认／水位）＋orientation 机构维持——**既不靠 RLI，也不是硬翻上下文**。粗粒度时间感（第几轮、还剩多少、域状态、水位）每一步都被动在场，模型没有产生「需要更精细节律信息」的体感缺口。

### 3.2 RLI 面的旁观证据

- **`section=rli` 消费＝0**（全轮 10 run journal 无一次调用）——与 0bf S3 基线 0/3 同值。
- **阈值推面（0bd ⑦）＝0 触发**（mechanical_audit 全 kind 覆盖式扫描无 rli 痕迹；对照 0bf S3 首现 2 触发——本轮节奏未持续越阈，判为真阴性可信度较高，检测式覆盖全 audit 流）。
- **LIF 域迁移 109 次**＝RLI 观测场的繁杂度实证（u/v 通道全程在算、域判定活跃——**通道活着，只是无人问津**）。

### 3.3 判读

1. **RLI 从来不是时间元认知的维持者**——它是「常开计算的旁路参考系」：0bf 生产化＝通道算力常开，读数只放 `section=rli` PULL 面，零注入（越阈推面除外）。模型不拉＝RLI 对模型面不存在。
2. **消费 0 的结构性原因**：budget/temporal 面已覆盖模型的粗粒度需求，RLI 的增量（节律、域倾向、失配概率）无体感缺口驱动；**0ck 注解只供给「存在性」，不创造「需求」**——与 0cf「面在役、模型不知晓⇒不消费」同族，且进一步：知晓也未必消费。
3. **对 0cj S4 判据的影响**：判据①「消费率>0」未达成（首笔真机数据）。按 152 批 §5.2 三层组合口径：第一层（注解）单独不足；第三层（平时可参考性注入）是否立项，**建议先补 0ck S4「注解在模型面可见」核证**（journal/回放可核）——「可见但不用」与「不可见」是两种不同的失败，处置不同（前者指向需求/时机问题，后者指向注解丢失）。
