## §1 发行内容

0.9.8 是 336 批「S2 真机十条＋两处 Web 修复」后的适用版。相对 0.9.6 的用户可见增量：

- **会话生命周期**：Web 关闭/删除/归档/恢复；会话表有界 32（LRU 只驱逐空闲）；`_orz/session_close|state|delete`；关闭后 prompt `-32010` 四要素；删除写 `.deleted` 墓碑不复活。
- **刷新/断线**：桥按工作区保活 child（默认 30 min，`ORZ_WEB_KEEPALIVE_SECS`）；刷新 attach 回同一会话；第二标签 409；保活过期显式提示。
- **撤回/补充**：`/rewind` 原文回输入框＋`recall_log` 审计；运行中输入进会话级队列，下一次 LLM 调用边界投递。
- **Web 细节**：交付面板、上下文读数、审批顶掉提示、后台「仅模型可见」、版本偏斜持久横幅、`orz doctor`、`orz --version`。
- **可靠性/安全**：CLI 删除经 close/lease 门；桥请求分表、审批跨 attach 重放、attached ingress 有界；跨区根、closing 可观测；错误四要素。
- **真机回归**：0dn S2 十条 10/10（75 断言，两轮）。
