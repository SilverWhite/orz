## 3. 立项内容（BACKLOG 0dd）

- **裁决要点**：对话生命周期控制（存档／新开对话／回档／删除）主权归用户手动；run 结束不得自动归档当前/存活会话；会话跨 run／跨日正常维持。
- **设计方向（S1 勘定）**：run 末自动归档精确触发面（0ak `incremental_archive_due` ACP 车道 vs 0cy 会话起点扫描 vs web 投影面——何者使用户必须手动回档待勘）；0cy 卫生闸自动面收窄口径（非存活会话自动收卷保留/改提示制）；`ORZ_GSA_HYGIENE=0` 临时手段边界注记（现仅关收卷闸、run 末归档是否受其管辖待核）。
- **批序（草案）**：S1 设计稿 → S2 落码＋钉子（钉＝当前/存活会话 run 末零 `session_archive`＋手动面恰等回归）→ S3 载体重建进体 → S4 真机复验（web 同会话跨 prompt/跨日续用不归档＋手动面回归）。
