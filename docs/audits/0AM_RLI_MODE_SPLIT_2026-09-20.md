的观察项（FR-8 实极点列 `ΔE ≡ Δu`／逐位相等），给出机制解释、损失范围的准确界定、用户裁决与本批落码。

**裁决（用户 2026-09-20）**：**读数层拆分＝做；形态层补振荡＝不做**。理由是只按动力学与效果判断（不考虑沉没成本与工作成本），RLI 作为预测与方向性组件，准确与优劣优先于内部形态的对称性。

## 1. 观察项的机制解释（为什么 `E ≡ u`）

实极点分支（`prog`，ζ=2.0）的两条闭式（[`rli.rs`](../../orz/crates/orz-assurance/src/lif/rli.rs)）为

```text
u₁ = φ·( u₀·cosh(μΔt) + b·sinh(μΔt) )          b = (v₀ + ζω·u₀)/μ
E₁ = φ·( |u₀|·cosh(μΔt) + |b|·sinh(μΔt) )
```

`E` 只是把 `u` 的两项各自套了一层绝对值。当 `u₀ ≥ 0` 且 `b ≥ 0` 时两项同号，绝对值不起作用，
两条式子**逐项同一运算次序**，故逐位相等——不是抽样巧合，是恒等式。

该条件在正常运行下恒成立：注入只踢 `u` 不踢 `v`、注入权重非负 ⇒ `u₀ ≥ 0`、
`b₀ = ζω·u₀/μ > 0`；且自由演化下 `b(t) = φ·(b₀·cosh(μt) + u₀·sinh(μt)) > 0` 保持为正。

**读数证据**（[`v3b`](../../../../../tb-eval/analysis/0am-rli-shadow-replay-v3b-fr8-2026-09-20.json)，137 runs）：

- 实极点列 137 runs × 4 个 ζ 值 = **548 行，`ΔE` 与 `Δu` 全部逐位相等（548/548）**；
- 通道总表 `prog` 的 `mean_of_run_mean_envelope` 与 `mean_of_run_mean_u` 同为
  `0.7336007109718689`（比值 1.000），其余四通道为 1.17／1.67／1.17／1.56（`slow`／`stall`／`err`／`deny`）。

**结论**：a3 解析包络在实极点分支上是**紧的上界**（上界恒被取到），因此在该分支上与前身 a1 水平
**不独立**；复极点分支上 `E = φ·√(u²+b²) > |u|` 泛成立，两锚点独立。

## 2. 判读（用户 2026-09-20，两条口径登记）

## 3. 损失的准确范围（三处分开算）

| 层 | 变化 | 性质 |
|---|---|---|
| 动力学层 | 二阶维度不变（仍是两模态）；模态的**数学类型**由共轭复模态换成两个实模态 | 失去周期/相位，得到明确的双时间尺度（慢 τ≈4.75 轮、快 τ≈0.34 轮，比 13.9:1，与 T̂ 无关） |
| 集合层 | 配极改后＝**4 振荡 + 1 单调**（改前＝5 振荡） | 通道集合层面的**形态多样性增加**；设计件 §6 的 ζ 语义区间 `[0.3, 0.6]` 全在欠阻尼区，故实极点分支是**族内新增实例** |
| 读数层 | `prog` 可用读数 5 → 4（`E ≡ u`；`r` 退化为纯衰减计数，参考尺度 `π/μ` 属快尺度） | 本条为**真实损失**，即本批处置对象 |

**形态层损失的边界**：仅限 `prog` **通道内部**（该通道不再有周期结构）。设计件
[`§3 a4`](../RLI_RESONANT_CHANNEL_BASE_DESIGN_2026-09-16.md) 明记「节律…实极点族结构性不可表达」，
[`§11`](../RLI_RESONANT_CHANNEL_BASE_DESIGN_2026-09-16.md) 的极点—语义表把 `prog 新鲜度` 映射到
**实轴慢极点** ⇒ `prog` 此前的振荡**不来自语义分配**，是「五通道统一 ζ=0.5」默认值的产物；
配极改在语义层是**对齐设计表**，不是抹平。因此要在 `prog` 内部恢复振荡形态，唯一与设计一致的路是
**补一对复极点**（回退 ζ<1 会复发骑阈，且 ζ→1 邻域数值脆弱）。

## 4. 裁决与理由（用户批准 2026-09-20）

**读数层拆分＝做**：拆出 `c_slow = (u + b)/2`、`c_fast = (u − b)/2` 进锚点面。其价值定位不是
「读数美化」，而是**功能上替代相位在预测上的作用**——复极点靠相位给出方向性（`v` 超前 `u`），
实极点没有相位，但换来「当前水平里多少会留下来、多少马上消失」的持久/瞬态配比，对 `prog`
（新鲜度/水平语义）比相位更直接。

**形态层补振荡＝不做**，三条理由：

1. **准确来源是锚定外部事件，自持振荡相反**：本批唯一一次大幅提准正是反方向——`prog` 由振荡改单调后，
   进度轴误差 38.2% → 10.3%（实际 10.0%）。振荡带来的读数变化是组件自己在动，不是框架在动。
2. **退回振荡会减少集合层形态多样性**：撤销实极点实例后 RLI 重新变成「全振荡型」；
   而「没有新事件就会消退」这一整类预测只能由单调型承载。
3. **节律信息类型已齐备**：`err/stall/slow/deny` 四条复极点通道都带 a4 节律锚点，重试风暴/卡住这类
   周期性现象本就落在它们身上；给 `prog` 再加节律传感器对「预测框架动作」的边际信息低。

**准确度的下一步落在判据选量，而不是加形态**：进度轴的低进度主张率 10.3% 与实际率 10.0% **已对齐**
⇒ 残差是**「哪一轮判错」的时序问题**，不是频率偏置。因此对照读数对象＝「低进度」判据用 `u_prog`
还是用持久分量 `c_slow_prog`（「持久推进水平低」而非「瞬时水平低」）。

**可证伪条件（本裁决的复议门）**：若回放显示 `prog` 的成功事件流存在**稳定周期结构，且该结构与
框架后续动作相关**（即节律读数能提高预测准确），则说明节律这一信息类型在 `prog` 语义词上确有缺口，
届时补复极点面**依据是信息而非形态**；反之若 `c_slow` 判据核读不优于 `u` 判据，则连拆分本身
都要重新评估其价值。

1. **「换判据用的量」这条假设不成立**（本语料零差异）。按 §4 的**预注册证伪条件**，
   低进度判据**维持 `u_prog`**；`c_slow` 判据不作为改进项采纳。
2. **第二轴近零不是动力学缺陷，而是采样粒度的直接后果**——正是用户 2026-09-20 的判读

3. **形态层「不做」的裁决维持，但理由要写准**：当时读数支持「改极点配置不产生可读收益」；
   现在已知瓶颈是**采样粒度**而非极点配置——形态层仍然不做，但**不是因为形态无用**，
   而是因为**读数分辨力已由采样粒度解决**（§9-1），补振荡面属重复投入。
   若日后仍需要「周期性/相位」这一信息类型（本批未证），再按 §4 的可证伪条件复议。
4. **拆分的价值定位**：作为**观测面**保留；判据面本批**零增量**（2 个判据完全等价），
   但其观测价值在事件级采样下成立（第二轴 85% 的样本带信息）。

## 10. 追加批（2026-09-20 用户令）：RLI 的**域级定位面**

**用户令**：「LIF 组件的一个作用就是作为外挂时间轴来帮助定位和事件追溯，请查看 LIF 组件的设计文档」
／「RLI 和当前 LIF 组件的域语义本就不必同格…只要 RLI 具有可用性即可」／「按照外挂时间组件的功能性和
原设计来说，RLI 得配上域级判断部分来方便模型进行进度定位和回看」。

**设计件查证**（[`机械层数学计算体正式设计`](../MECHANICAL_LAYER_MATH_CALCULUS_DESIGN_2026-08-30.md)）：

- **§3 F2 temporal 分区渲染规格**——定位：「**观测记录面——时间轴上的特征域事实序列**；域＝模型进入
  不同思维／行为动力学阶段的观测标记」。数据模型＝决策轮行（`t`／`domain`／`entry_round`／
  `dwell_rounds`／特征）＋**存档 spike 点位**（`DomainSpike{t, domain}`，驻留轮数由相邻点推导、
  不单独存储）；查询面 `Now | Recent(k≤20) | History | Feature(name,k≤20)`。
- **§4 F3 LIF 时间外挂计算规格**——时间外挂的算法面（特征集／更新律／T̂ 估计器）。

**RLI 现状对照**：**域级判断部分已存在**（0am 改造四项① 落码：四象域机器 ＋ 逐决策轮域行 ＋
域切换点位全量 ＋ `now`／`recent`／`history`／`feature` 四个 PULL 面）。与设计件的差距只有两处：

1. **定位要素缺失**：RLI 的切换点位原本只带 `{t, domain}`，`history` 只渲染「域 @ 秒」——
   没有轮次对齐与驻留；而 temporal 的 `history` 有 `from → to @ t (round N, dwell M) [recovery]`。
   「进度定位与回看」要能把域事实对齐到**轮次**，这是外挂件的基本要素。
2. **域行窗口 20**（与 temporal 的 `recent`／`feature` 同格，属运行时查询窗，非状态面）。

**本批落码（四项）**：

1. `RliDomainSpike { t, domain, round: Option<u64> }`——**RLI 自有类型**（不复用 temporal 的
   `DomainSpike`）；`round = None` 表示旧侧车未记录（FR7 口径：不可得与真值 0 必须可分辨）。
2. `RliDomainMachine::segments()` → `RliDomainSegment { from, to, at_t, at_round, dwell_rounds,
   recovery }`——由相邻切换点推导（末段用当前轮收口；`recovery` 同 design §3.2：
   Stuck／LowProgress → Normal）。
3. `rli.history` 渲染改为**段表**：`from → to @ t (round N, dwell M) [recovery]`，
   **全 run 无窗口**；`rli.now` 的「上一迁移」行补轮次。
4. **语义不必与 LIF 同格**（用户裁决）：RLI 域语义保持自有（压力轴＝`v`／`E` 原生覆盖、
   进度轴＝prog 水平），只借用 temporal 的**信息形态**（定位要素），**不借用其读数**——
   早期文档「与 temporal 同形」的措辞按此口径理解：同形＝同信息形态，非同读数、非同格。

**登记**：

- RLI 的域时间线是**全 run**（无 20 窗），深于 temporal 的迁移日志（≤20）——外挂件功能上的一项优势，保持。
- **影子维持默认关（用户裁决 2026-09-20）**：RLI **依旧作为影子组件**，需 `ORZ_LIF_RLI_SHADOW=1`
  才构造；**下一步裁决待 0bc 实测之后**——实测窗内开启影子取读数，是否常开／是否替换 LIF 由该批
