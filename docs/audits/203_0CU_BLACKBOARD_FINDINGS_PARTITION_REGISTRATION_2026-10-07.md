## §2 设计定稿要点（详见设计稿，此处只记裁决锚点）

1. 分区名定案 **`findings`**（候选比较 findings/facts/log/worklog/results/knowledge，取模型
   最顺手最通用；enum 值小写单数与 plan/notes 同风格）。
2. 存储＝黑板根 `findings: Vec<NoteEntry>`（notes 同构形态）；盖章/≤8K/ReadOnly 放行/事件出账
   逐字照抄；`PartitionRevisions`/PULL 徽章/epoch 快照/会话快照/水位/压缩折叠行池全部随动 +1，
   零新机制。（**209 批勘误 2026-10-07**：「压缩折叠行池全部随动 +1」表述有误——折叠快照
   B 近窗明细池只含 exec/edits/tool_actions，findings 为非折叠分区、零触点即正确实现；见设计稿
   §4.1 勘误。）
3. **契约面零改**（已核实）：事件 schema 无 section 闭枚举、判官不校验 section 值、权限桥同
   工具、探针表同工具、折叠展开集不含 notes 类分区。
4. 三处「不照抄」的定点（用户同意）：`model_note_count` 不含 findings（D1 责任不抵扣）；文案
   走 0cl 纪律（增量 ≤3 短句）；plan 描述原样不动。
5. 与压缩白名单块互补不耦合：台账在板（PULL）、保命在前言（常驻），模型自选。
6. 批序：S1（本批）→ S2 落码＋8 类钉子 → S3 载体进体 → S4 真机核证（不设使用率判据——自由
   写入口径）。
