## 2. 关键口径与实现落点

### 3a 空槽「（无）」

- 压缩五段槽（目的/计划/变动文件路径/注意事项）空态统一渲染「（无）」——
  取代「（未设置）」/空串/「（本窗口无编辑）」/「（无注意事项）」混用
  （D4，设计 §5）。后续衔接槽是固定中性占位（非空槽语义），不改。
- `build_status_line` 无目标时同样统一「（无）」（半角 `(未设置)` 一并退役）。
- 文档措辞同步（summary.rs 常量注释、测试注释）；`NOTES_FACTS_EMPTY`
  常量值改为「（无）」，引用方（marker/存档/测试）随常量自动一致。

### 3b plan-epoch 生产面退役（R4）

- **marker**：`黑板 plan_epoch: N` 行退役 → `黑板会话: <session id|（无）>`；
  回查行与后续衔接槽不再引导 `epoch` 参数（历史全量保留在 live 黑板，按
  域/轮数展开或 since/receipt_id 回查）。会话 id 经 `SharedLoopServices`
  新增 `session_id` 字段贯通（ACP `with_retrieval_mode` 已带 session id；
  CLI/测试 = None →「（无）」）。
- **blackboard_read `epoch` 参数**：模型工具声明在生产面移除 `epoch`
  property 与描述引导；仅当控制器配置归档目录（`--plan` 诊断/测试域）时
  恢复声明（cross-epoch 归档读）。生产面携带合法 epoch 的调用仍 fail-loud
  （显式退役报错，不静默回退 live）。live-only 分区（session/retrieval/
  entities/deps）的 epoch 拒绝文案维持。
- **生产接线**：生产入口本就不配置归档目录、不触发 with_plan/rotate/claim
  （B3 前已仅剩 `--plan` 与测试域）；`.gsa/blackboard/epoch-*.json` 生产面
  不再写入为现状确认 + 头注登记。路径槽溢出指针在无 epoch 时回退摘要存档。
- **保留**：`--plan` 诊断模式（main.rs `run_plan`）与其 epoch 读写面不动。

### 3c 用户侧疲劳提醒（E9/§10.1/§11.2/§13.2）

- 新纯函数模块 `fatigue.rs`：水位百分比、档位 50/70/90、单次给**最高未
  提醒档**（巨幅跳跃不刷屏）；70 档换对话建议需会话压缩 ≥2（否则仅事实
  水位行）；90 档始终；50 档无门槛。文本软措辞、只给事实。
- W 复用 `render_fold::FoldParams`（默认 10 MiB，env
  `ORZ_BLACKBOARD_LIVE_BUDGET_BYTES`）；`fatigue::live_budget_bytes()` 为
  宿主面统一入口。水位 = 黑板 live 侧车紧凑 JSON 字节（`Blackboard` 序列化
  长度，与 B2 折叠同口径）。
- ACP：`StoredConversation` 增 `context_compressed_total` +
  `fatigue_tiers_notified`（serde default/skip，legacy 兼容）；每次成功 run
  末按本 run journal 的 `context_compressed` 事件数累加，计算水位与待提醒
  档，投递档位记入侧车；响应 JSON 增可选 `user_notice`（不进模型消息）。
- codex_app：`finish_turn` 把 `user_notice` 追加到展示用 agentMessage 文本
  最后（持久化会话由 ACP 侧车完成，不含附言）。
- CLI 单 run：无独立 UI 通道 → run 结束 stderr 附言（§11.2 降级口径）；
  压缩计数 = 本 run journal 事件数。

### 3d 存档单包 gzip + `session_archive`（E10/§11.3/§12 R3）

- 契约先行：新增
  `runtime/session-archive-event-payload-v0.2.schema.json`；run-event-v0.2
  枚举 52 → 53（`session_archive`）、run_id 前缀扩展 `ARC`；verifier
  `PAYLOAD_SCHEMA_BY_EVENT_TYPE_V02` +1；fixtures
  （payloads minimal/constraint + envelope）；python conformance 计数
  52→53 同步。`EventType::SessionArchive`（orz-assurance）与 TUI
  bridge/events/projection 映射同步。
- `archive_session_package`（orz-host/acp_server.rs）：关闭时读取既有
  conversation sidecar 原样 gzip（纯打包零内容变换）→
  `.gsa/archives/<session8>.json.gz`（tmp + rename 原子写、sha256 digest、
  有界重试 3 次）；随后专用 `ARC-<session8>-<n>` run journal 记录
  `session_archive`（run_preflight → session_archive → run_finished）。
- `close_session` 后台 best-effort 触发（不阻塞关闭；失败只 warn）。
- digest 字段允许失败态空串（无成品可计）；fatigue_pct 可选（0–100）。
