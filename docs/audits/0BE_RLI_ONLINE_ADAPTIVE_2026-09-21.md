## 2. S1 设计决定（本批自行裁决部分，均已落黑板书；此处为收口版）

### 2.1 λ̂（会话内在线到达率估计；估计式）
- 输入：`prog` 通道的成功事件**到达间隔**；**间隔先钳制**到
  `[0.5 s, 3600 s]`，再进 EMA（α = 0.2，`RLI_LAMBDA_EMA_ALPHA`）。
- **退化路径**：不足 2 个间隔（`RLI_LAMBDA_MIN_GAPS`）＝**未激活**——
  `prog` 前推**严格**退回自由衰减（与 0am 版行为一致）；未激活面以
  `Option` 表达（`None`＝不可得，与真值 0 不混同——FR-7 口径）。
- λ̂ 状态（间隔 EMA＋样本计数）随通道快照持久（会话级自适应参数）。

### 2.2 `prog` 前推修正（闭式、O(1)、无拟合）
`prog` 是**冲量重置型**通道（成功到达把 `u` 置 1；`v` 不踢）：闭式自由演化
只含衰减、不含未来注入 ⇒ 对拍中系统性偏低。修正模型：

```text
E[u(t+τ)] = e^(−λ̂τ)·g_free(τ) + λ̂·[Ĩ_cosh(q, μ, τ) + β_c·Ĩ_sinh(q, μ, τ)]
q = ζω + λ̂,  β_c = (v₀ + ζω)/μ
Ĩ_cosh = ∫₀^τ e^(−q a)·cosh(μa) da,  Ĩ_sinh = ∫₀^τ e^(−q a)·sinh(μa) da   （闭式）
```

- 语义：**自由衰减 ＋ 期望注入项**（末次注入年龄的密度 λ̂e^(−λ̂·)`）；
- **同刻注入近似**（未来注入时刻的 `v` 用当前 `v₀` 近似）——如实登记为
  近似面（报告 §6 摩擦）；
- λ̂ = 0 ⇒ 严格退化为自由衰减；λ̂ → ∞ ⇒ 期望 → 1（持续注入）；τ → 0 ⇒
  连续回到 `u`；对 λ̂ 单调不减；与数值积分对拍误差 < 1e-4（测试钉）。
- 仅 `prog` 通道使用（其余四通道＝纯自由演化闭式，读数逐位不变——离线
  对拍证实）。

### 2.3 分通道 horizon ＋ 短视锚点
- `rli_horizon_steps(kind)`：Slow=1、Stall=2、Err=10、Deny=30、Prog=10
  （语义常数、禁拟合；依据＝对照文档 §2/§2.1 逐通道最优档）。
- 新增显式接口 `prediction_at(steps, t̂)`；`prediction()` 保留「10·T̂」兼容义
  （探针/旧读者同源）。
- **a2s 短视锚点**（`prediction_short` ＝ `1·T̂` 闭式前推）独立成档；feature
  名集合 11→13：新增 `pred1_err`／`pred1_prog`（与 `pred_*` 分列）。
- 文档漂移收口：模块头与字段注释的旧「一阶短视 `u+v·T̂`」口径退役
  （现实＝闭式前推；两处注释同步改写）。

### 2.4 繁杂度（用户面机械提醒；机制照抄 E9）
- **指标链**（会话级；禁用 `prog`——h≥2 结构性负会报假疲劳）：
  ```text
  ρ_i    = |pred_i − real_i| / |issue_u_i − real_i|      （逐样本误差比；分母≈0 跳过）
  ρ_ch   = 窗（16）内 ρ_i 的中位                          （逐通道）
  ρ_cur  = 各就绪通道 ρ_ch 的跨通道中位（≥2 通道才产出）   （四条复极点通道）
  ρ_base = 前 16 个 ρ_cur 样本的中位（冻结）               （本会话前段基线）
  c      = clamp(ρ_cur / ρ_base, 0.25, 4)                 （放大倍数）
  θ85/θ95/θ99：c 的 (1−q) 分位追踪（θ 同法乘性更新，η=0.05）
  锁存    = (c ≥ θ_t) ∧ (c > 1)                            （含中途尖峰）
  ```
- **配对口径**＝决策轮：预测在轮 `r` 发出、**首个 ≥ 到期时刻的决策轮**消费
  （与对照文档 §1 同口径）；跨 prompt 未决算预测随快照保留。
- **档位键** `q85`/`q95`/`q99`——与水位档 `50`/`70`/`90` **分开命名、分开
  簿记**（会话侧车两套字段）；每档一次（投递即落档；跳跃一并落档）。
- **投递形态**：run 成功路径的 `payload["user_notice"]`（与疲劳文案按
  `\n\n` 拼接）；**不进模型上下文**；失败 run 不更新档位（SUCCESS-ONLY）。
- **退化路径**：影子未启用／样本不足（基线未冻结）＝不投递（机械如实）。

### 2.5 自适应参数轨迹（侧车）
- 决策轮粒度追加一行：`{round, t, λ̂, c, ρ_base, θ85/95/99}`；
- cap 128（环形、旧在前）；量化 3 位；随 RliShadowSnapshot 持久
  （**复算可核**：轨迹与在线自适应同源同序）。
- 侧车 schema 保持 `rli-shadow-v1`：新字段全部 `serde(default)`（legacy
  侧车零迁移）；`Option` 字段区分「未记录」与真值（FR-7）。
