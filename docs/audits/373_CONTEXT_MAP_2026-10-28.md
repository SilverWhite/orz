## §0 结论

`context_manage(mode=map)` 已落码：

- 复用 `blocks_outside_slider` / `face_markers` / `slider_readout` / `archive_tag` / `relative_block_archive` / `relative_clear_archive`，**不新建分块/台账/状态存储**。
- 每行＝块号 / 轮次 / token / 状态 / 台账 `[seq]` / 定位符 / 回放路径；状态字母 `T/C/X/B/L/R`。
- 硬预算 **≤1K token（chars/2 口径）**；超预算保留前缀并标注 `... +N blocks`。
- 仅 `mode=map` 本身；夹带 `summary/whitelist/handover/keep_recent_rounds` 整调用 exit 1，零副作用。
- 不进模型面常驻：只有工具调用结果回流；不写 marker、不置压缩窗口、不落 `ContextCompressed`。
- `context_manage` schema enum 增 `map`，description/黑板 guide 同步；仍属 ReadOnly 类，权限表无需新增。

## §1 输出形态

```text
[context_map v1] run=RUN-... total=2 compressible=2
#1 r1-1 5Ktk L
#2 r2-2 5Ktk L
图例: T=截断 C=压缩 X=清零 B=跨边界 L=原文 R=残段；path=按块回放
```

已压缩/已截断块附 `path=.gsa/compaction/blocks/<tag>-block-000N.md`；清零块附 `path=.gsa/compaction/blocks/<tag>-clear.md`；跨清零边界标 `B`（前段已移出，后段仍在窗口）。无块时显式 `no blocks outside slider`。
