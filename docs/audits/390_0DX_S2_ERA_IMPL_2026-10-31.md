## §2 宿主 idle 路径机械细节（诚实登记）

- 裸 `/checkpoint`（无随行输入）走 ext `orz/checkpoint`（TUI）或 prompt 路径早返：折叠＋写回续接包＋**不拉起 run**；事件载荷待命。该路径经 prompt 进来时已消耗一个 run 序号与 bootstrap 目录（与失败 run 同形态的空 run 目录，机械无害）；ext 路径不消耗。
- `handle_session_checkpoint`（ext 面）与 `handle_recall` 同款 idle-only 互斥口径（runs 表查询＋Busy 四要素；check-then-act 窗口与撤回面同级登记）。
- ext 折叠面使用会话侧车快照构造黑板/LIF 读数（无 run、无活体引擎）；slider/block 参数经 `controller.context_compact_{slider,block}_tokens()` 读数（ext 面缺省值 160K/32K 与生产单源同值）。
- 检查点 sink（0dq）经共享 cell 携带时代账面/待命载荷实时值（折叠发生在 sink 装配之后；闭包按实时值重建续接包）。
- era 折叠拒绝（无可折叠内容）在自动触发路径＝同代继续（tracing info，不静默不阻塞）；在裸 `/checkpoint` 路径＝机械回执（`时代切换未执行：…`）。
