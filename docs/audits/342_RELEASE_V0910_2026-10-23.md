## §1 发布内容

相对公开最新版 0.9.8，本版包含：

1. 回档后同会话 run 改按数值序稳定回放，消除 mtime 压平造成的乱序；
2. 会话清单投影权威关闭态，Explorer 分列活跃／已关闭／归档会话；
3. 历史 8 位 conversation ID 只在 orientation 与 activation 双侧车一致时迁移，冲突 fail-closed；
4. 切换会话固定为先 load 新目标、再换绑定、最后 `close(switch)` 旧 host 附着；load 失败保留旧绑定；
5. Windows／Linux 0.9.10 双平台重建，Windows 装机位换装与 ACAF 重 provision，Linux static PIE。

README 中文／英文发布面同步到 0.9.10，安装命令、Latest 链接和更新说明均已更新。
