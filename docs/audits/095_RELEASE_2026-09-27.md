## 5. 边界与未做项

1. **包内不含 `carrier-manifest.json`**（有意为之）：该清单为站点件——清单在位时，包内
   `README.md`／`SHA256SUMS` 一类顶层常规文件会被「清单外新增」检测报出告警横幅
   （[`carrier_integrity.rs`](../../orz/crates/orz-host/src/carrier_integrity.rs) 的排除集只覆盖清单自身与 `.bak`／`-bak` 链）。
   故发布包保持「三件套＋README＋SHA256SUMS」形态；**是否把 README／SHA256SUMS 纳入排除集并把清单打进包**，留后续载体重建批裁决（本批不改代码，避免使已发布载体与源码面失配）。
2. **矩阵 ③④ UI 点击级重走未做**（093 §10 为 API 级实证）；**链首就绪承接采样未做**——均留狗粮轮。
3. **0bw④ git 自动检查点**维持设计登记（不改码，故不在本版）。
4. **0bw⑤ CFA enforce** 维持不翻（1123／1124 零行）。
5. **未做双平台预检**（默认口径，沿 081 先例）。
