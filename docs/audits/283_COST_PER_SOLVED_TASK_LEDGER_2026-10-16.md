## §6.1 r4 逐档形态学补记（2026-10-17 追加，用户令）

**问法与口径**：失败档是「撞墙晚、把最后一档烧满」，还是「harness 磨到超时」？源＝
`r4_checkpoint_ledger.jsonl`（198 行，含 `stop_reason`／`rounds`／`elapsed_sec`／
`timeout_cfg`＝7200 s／`killed`／`cancelled`／八指标）。先沿 §2 同一口径剔除 p18 断盘件那一对
（中止件 ckpt1／ckpt2，后者无读数）⇒ **196 行**；再剔两行**无时长**的机械截停（p11 `eve_industry`
ckpt5／p30 `rejector` ckpt2，均 `rounds=0`）⇒ **194 行**进入形态学统计，通过 144／失败 50。
**本补记不重算金额**，§2 的 196 档分母不变。

| 读数 | 通过档（core＝1.0，144） | 失败档（core＜1.0，50） |
|---|---|---|
| 墙钟中位／均值 | 776 s／835 s | **1016 s／1223 s（1.47×）** |
| 模型轮中位／均值 | 69／67.5 | **86／84.3（1.25×）** |
| 最长单档 | 3,294 s（46% 上限） | **3,518 s（49% 上限）** |
| 收尾形态 | `end_turn` 144/144 | `end_turn` 50/50 |
| killed／cancelled／≥90% 上限 | 0／0／0 | **0／0／0** |

- **不是磨到超时**：194 档全部由模型自行收尾（`end_turn`），零 killed、零 cancelled、零档达到
  7200 s 的 90%；失败档中位只用到上限的 **14%**，最长 49%。
- **也不是末档死磕**：失败分布＝ckpt1 7／ckpt2 **12**／ckpt3 7／ckpt4 8／ckpt5 9／ckpt6 3／ckpt7 3／
  ckpt8 1——八档皆有，峰值在第二档，末档最少。
- **代价结构**：失败档比通过档多跑约一半墙钟、四分之一轮次，然后自行收尾（50 档中 2 档全零、
  48 档 partial）；时间份额＝失败档 17.0 h／全轮 50.4 h＝**33.7%**。
- **结论（对 §6 形态学句的机理补正）**：SCB 的「失败不便宜」主要由**宽度**构成——36 题／196 档
  （每题 3–8 档、中位 5）、逐档重做，叠加每档约 1.47 倍时长——而非超时磨盘或末档烧穿。
- **边界**：墙钟与轮次是 effort 代理，非金额；金额口径见 §2（题级 ¥6.40 对 ¥5.49＝1.17×，与档级
  1.47× 不冲突——题级被多数通过档摊薄）。零轮机械截停两档单列，不计入形态学样本。

## §7 边界与不得宣称

1. **k=1、成功样本极小**：r4 端到端成功 4 例，±1 题即 ±25%；TB 2.1 为 k=1 筛查轮。
   本批数值是**当前形态的读数**，不是 harness 的「成本能力」。
2. **不得跨口径混用**：档级／题级、core／strict／isolated、196／36 分母必须成套声明；
   36 倍差距即来自口径，而非来自轮次好坏。
3. **credit 不抵扣**：DeepSeek 就 10-08～10-14 故障赔付的 +464.70 credit 覆盖了 0cw、r3 几乎全部
   与 r4 的 10-14 前支出（r4 该段 ¥105.40）。若按净额摊派，0cw／r3 的单任务成功成本将变成 **¥0**
   ——数值失去意义，故本批一律用毛额，返还单独登记。
4. **不得与论文／榜单直接对比**：V1／0cw／r3 分别为连续形态、泄漏混合形态与止损子集；r4 为
   净室官方形态但仍是 k=1、单一廉价模型、非官方成绩提交。
5. **TB 2.1 数值为重构而非实付**：单价的取值区间来自本仓自测（§5），该窗真实价格档未取回；
   控制台分项到手后可原地升级为真口径（口径与公式不变，只换分子）。
6. 本批**零 API 调用**：全部为既有台账/journal 的只读复算，未产生任何新消费。
