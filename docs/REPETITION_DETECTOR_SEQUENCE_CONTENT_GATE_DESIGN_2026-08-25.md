## 2. 定案设计（2026-08-25 用户裁决）

### 2.1 原则

- `REPETITION_MIN_RUN_CHARS`（L）= **400 维持**，不采用提档到 1000；
- 路径①（滚动哈希任意偏移精确 span）保留给**所有内容**（含序列内容）；
- 路径②（3-gram 比例 0.70）与 stall 兜底（600s/64K）**不变**；
- 二级确认「无可切分点→直接判真」分支新增**内容判别门**，把合法有界
  回显与病态无界循环按「重复次数」分开，而不是按内容类型整体换路。

### 2.2 序列样判定（2026-08-26 扩展：DNA/RNA + 蛋白两族）

- 新常量 `REPETITION_SEQUENCE_LIKE_RATIO: f64 = 0.90`（DNA/RNA 族；
  初值，S4 校准范围 0.85–0.95）；
- 新常量 `REPETITION_PROTEIN_LIKE_RATIO: f64 = 0.95`（蛋白族；初值，
  S4 校准范围 0.93–0.97）；
- DNA/RNA 字母表 = `{A,C,G,T,N,U}`（大小写均可，DNA/RNA 通用）；
- 蛋白字母表 = 严格 20 标准氨基酸 `{A,C,D,E,F,G,H,I,K,L,M,N,P,Q,R,S,
  T,V,W,Y}`（大小写均可；刻意不含 B/X/Z 歧义残基与 U/Sec——这些若计
  入会纳入英文常见字母 B/O/U，使英文无间隔长串占比逼近/超过阈值）；
- `sequence_kind(span)`：span 非空且 DNA/RNA 占比 ≥ 0.90 → DnaRna；
  否则蛋白占比 ≥ 0.95 → Protein；否则非序列样。单次扫描、整数比较。
  两族任一判真即序列样；同判真时 DNA/RNA 优先（审计 kind 区分）。
- **覆盖面实证（2026-08-26）**：英文无间隔长串（Gettysburg Address 去
  除标点/空白后 400 字符切片）的蛋白 20 字母占比 = 0.8975——若蛋白共用
  0.90 裕量仅 ~0.25%（覆盖面过广，否决）；0.95 下裕量 ≥5%。真实蛋白
  序列（UniProt P35579 myosin-9 第 1–400 位）占比 = 1.00。DNA/RNA 0.90
  维持不变。

### 2.3 序列族命中门槛

- 新常量 `REPETITION_SEQUENCE_HIT_LIMIT: usize = 5`（初值，S4 校准
  范围 4–6）；
- 无切分点 span 经 `sequence_kind` 判定后分派门槛：
  - 序列样：流内累计 ≥ **5** 次才 trip（1–4 次仅审计，WARN 带
    `sequence_gated` 标注 + kind（dna_rna / protein）+ ratio +
    hits/limit）；
  - 非序列样（如无标点英文长串、纯标识符）：维持 ≥ **3** 次 trip
    （`REPETITION_HIT_LIMIT` 不变）；
- 有切分点 span 走原「标点块内部重复确认」0.50 覆盖路径，**不适用**序列
  门（代码类行为不变）；
- content/reasoning 两族统一；间隔不重置、流结束丢弃、consecutive 与
  `DEGENERATION_LIMIT` 语义不变。

### 2.4 为什么不是 L=1000 / 为什么不是整体走路径②

- **L=1000 是移动边界**：EGFP 完整编码约 720 nt 恰好小于 1000，但
  ≥1kb 序列块或长代码块原样重复仍会命中；且 L 越大，真退化凑满命中
  越迟钝（烧更多 token 才 trip）。
- **整体走路径② + stall 有检测盲区**：路径②是「最近 1K token 的 token
  三元组重复率 > 0.70」，对「同一长 span 重复但上下文变化」的循环无感；
  stall 只抓「无 content/tool_calls 输出」；散文+序列混排还需要内容
  分类路由，引入新的边界与双路逃逸可能。
- **本定案**保留精确 span 检测（任意偏移、与上下文无关），用内容门把
  合法有界回显（本次 3 次）与病态无界循环分开：真循环会持续产出相同
  span，5 次门槛很快越过；合法回显有界，1–4 次仅审计。

## 5. 边界登记

- 序列门只覆盖「无可切分点」路径；FASTA 头行、带数字/间隔符的序列内容
  有切分点，仍走标点块确认（不受影响）。
- **数字非切分符（2026-08-26 勘误）**：切分符集合 = 标点 + 空白（`-` 等
  间隔符属标点，会切分）；**数字不是切分符**——带数字但无标点/空白的
  序列 span 仍走 `sequence_kind` 判定（数字压低占比：DNA/RNA 侧 >10%
  数字即不判；蛋白侧占比仍 ≥0.95 时判蛋白）。FASTA 头行的 `>` 与空格
  是切分符，走标点块确认。
- 纯 ACGTN 字母构成的代码/标识符（如 base64 串）若占比 ≥0.90 会误入
  序列门（门槛变松为 5）——登记为已接受边界：该类长串原样重复本不常见，
  真循环仍会 ≥5 次触发；S4 实机观察。
- 蛋白族歧义残基 B/X/Z 与 U（Sec）不计入蛋白字母（U 计入 DNA/RNA
  字母）；含此类残基时蛋白占比下降，低于 0.95 落回非序列 3 门槛——
  登记为已接受边界（低质量蛋白序列原样重复 3 次仍可能误杀，S4 观察）。
- 门槛初值 0.90 / 5 的校准范围与 3-gram 0.60–0.70 近重复漏判既有边界
  互不影响。
