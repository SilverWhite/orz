## 0. 触发与依据（为什么必须重跑）

**代际事实（一手来源）**：DeepSeek 于北京时间 2026-09-10 12:00 发布 V4.1 Flash
并下线 V4 Flash；模型名 `deepseek-v4-flash`（本项目全部官方跑批固定使用该名）
被**暂时路由**到 V4.1 Flash，**兼容路由无公布截止日**。

**盘面事实（地面真值）**：`jobs-official` 全部官方批次 234 份 `result.json` 全量
扫描 → verifier 1.0 共 **81 条**、涉及 **77 题**；其中跑在 V4.1 Flash 上的通过题
**有且只有 1 题**（path-tracing-reverse，09-10 14:11–14:27），其余全部为真 V4 Flash。
详见 [`OFFICIAL_LEDGER_MODEL_GENERATION_ANNOTATION_2026-09-12`](audits/OFFICIAL_LEDGER_MODEL_GENERATION_ANNOTATION_2026-09-12.md)。

**项目既有裁决**：口径分歧（65/74/76/77）保留、不并轨——「目前成绩并不可靠」。

**结论**：旧账面是混代际数据，不能充当新后端的对照基线；重跑的目的**不是刷新分数**，
而是建立一份**单代际、语料冻结、载体版本唯一**的新基线。

## 2. 代际记录纪律（本轮口径，避免重犯「混代际不自知」）

## 3. 批次计划（分批，不一次跑完）

- **跑批口径（2026-09-13 用户裁决）**：新一轮**按官方口径**执行（官方 harness +
  官方墙钟 + `tb_agents/orz.py` 透传的 orz 载体；网络策略沿用官方 89 题 PUBLIC），
  并把结果**上传 Harbor**（官方提交面；装置侧代理入口见 `scripts/setup_harbor_proxy.ps1`、
  透传入口见 `scripts/orz_acaf_run.ps1`）。即：本轮数据以「官方口径 + Harbor 记录」
  为对外版本，本地审计只作过程证据。
- **每任务试次数 = k（2026-09-13 用户指示 k=1；同日核实边界）**：本轮按 **k=1**
  跑 89 题（每题单次尝试、单代际）。**边界（一手来源）**：官方榜单 CI 要求
  **89 题 × 每题 ≥5 试次**（`leaderboard/src/leaderboard/ci/static_analysis.py`
  `MIN_TRIALS_PER_TASK = 5`；`leaderboard/SUBMIT.md`「full task coverage with
  ≥ 5 trials per task」），因此 **k=1 的记录可照常 `--upload` 到 Harbor，但不构成
  可上榜单的提交**（榜单校验会判 "N task(s) below 5 trials"），且 `pass_at_2…5`
  列无意义；k=1 的对外口径只能表述为"官方流程 + 单次尝试的基线扫描"，不得表述为
  榜单成绩。执行入口已参数化：`run_official_2.1.sh` 的 `K="${K:-5}"`，默认 5
  （榜单口径），`K=1 bash run_official_2.1.sh 1` 即单次扫描；两种口径的语料身份
  完全相同（冻结清单按题不按试次）。
- **第 0 步：语料与阈值冻结（P2-15 S1/S2）**——89 题 + sha256 清单 + 阈值干跑校准，
  runner 与 oracle isolation 已在位。起跑时刻即该立项的天然窗口；不冻则本轮数据
  同样不可复现。
- **分批形态**：沿 R1 的 c1–c9 形态分批推进；每批落资源事件遥测
  （`host_resource_snapshot` / `host_resource_denied` / `reclaim_performed` /
  `process_tree_reaped` / `resource_limit_hit` + 终端形态）+ 零 400 / 哨兵 / 命中率统计。
- **本轮承载的开放项（一鱼多吃，沿用 0o「一份 journal 喂多个判据」纪律）**：
  - 0b ③（make-doom reward 复验）/ ④（compile-compcert + hf-model-inference 交叉）/
    ⑤（89 题 5 批）；
  - 0o T4（TB2 容器批）/ T5（离线回放）判据，T6 统一收口；
  - 0t S4 实机复验；P2-12 S4 / P2-13 B4 / P2-14 S4 的长会话遥测（make-doom 类）；
  - 0d 后续 3/4/5 通用统计（零 400 + 命中率 ≥90% + 哨兵 ≤3）；
  - **0z S4** 判据中的「真机长任务复跑（含重活路径）」由本轮天然承担。
    **边界**：满盘注入与 abort 注入是**受控注入项**，须单独安排执行，不靠「等它
    自然发生」充当证据。
- **被本轮取代**：0u（R4 未通过 15 题复跑）与 0t S4 的单独批次——同载体、同代际、
