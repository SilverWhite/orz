## 1. 提取的完整公式（verbatim）

### 1.1 三态核心动力学（离散时间步，dt=1；可选 n_substeps 指数 Euler 子步）

```text
V[t]            = β_V · V[t-1] + I[t] − g_A · A[t-1]     膜电位（含适应电流反馈）
A[t]            = β_A · A[t-1] + spk[t]                  适应电流（spike-frequency adaptation）
spike_accum[t]  = β_θ · spike_accum[t-1] + spk[t]        脉冲历史累积（阈值梯度路径）
θ_eff[t]        = θ_base + g_θ · spike_accum[t-1]        有效动态阈值（取 t-1 累积）
spk[t]          = Θ(V[t] − θ_eff[t])                     训练期 surrogate 梯度；推理期硬阈值
复位            V[t] −= spk[t] · θ_eff[t]                subtract reset（LIF 传统）
```

三维状态语义：V＝膜电位（标准 LIF）；A＝适应电流（Ca²⁺ 通道动力学）；θ＝动态阈值
（Na⁺ 失活/使用依赖可塑性）。**退化路径精确**：g_A=0, g_θ=0 → 1D 标准 LIF；
+g_A → 2D LIF+adaptation；全开 → 3D。

### 1.2 β-锚点参数化（设计哲学：「复刻行不通，演化和硅基特调」）

```text
β_V  = sigmoid(clamp(β_raw, −10, 10))                    唯一底层锚点
δ_A,δ_θ = delta_range · tanh(·)  ∈ (−0.1, 0.1)           有界小偏移
β_A  = β_V + δ_A（beta 空间，clamp [0.01,0.99]）或 sigmoid(β_raw+δ_A)（logit 空间）
β_θ  = 同构于 β_A
```

单锚点 + 有界偏移（R4/Izh 教训：避免 4 参数 8.2× 放大）；β(1−β) 梯度自正则。

### 1.3 M2 有界耦合（从 LIF 稳态 f-I 方程导出）

```text
softplus 模式：g = softplus(g_raw) ∈ [0, ∞)
M2 模式：      g = G_max · (1−β.detach()) · σ(g_raw)  ⇒  有效增益 g/(1−β) ≤ G_max
```

### 1.4 指数 Euler 子步（bit-exact 复合）

```text
n 子步时：β_sub = β^(1/n)；输入/脉冲贡献按 (1−β_sub)/(1−β) 分摊
⇒ n 子步串接的总衰减/总注入与单步 bit-exact 等价（回归保护已声明）
```

### 1.5 分析量

```text
τ_V = −1/ln(β_V)，τ_A、τ_θ 同构（单位：timesteps）
E   = g_A / (1−β_V)                 单脉冲总适应抑制（稳态）
R   = g_A · (1−β_V) / (1−β_A)       适应强度 × 时间常数比
```

### 1.6 β_mod 神经调制（R20，可选）

```text
β_V_eff = β_V^(1+δ)，δ = s_A·tanh(W_A·x) + s_C·tanh(w_C·spike_accum.detach())
'current' target 为容量零对照（δ 注入电流而非 β_V）
```

### 1.7 局部塑性（在线自适应本体；零梯度、事件驱动）

```text
BCM  稳态阈值：θ_base ← θ_base + η_θ · (running_rate − target_rate)，clamp θ_base_min
IP   内在可塑性：β_raw ← β_raw + η_β · tanh(ln((in_var + ε)/target_var))（logit 空间，clamp ±10）
统计量：running_rate / running_input_mean / running_input_sq = per-neuron EMA（decay=0.99）
```

**这是"在线自适应"的关键事实：LIF3D 公式族自带零梯度、在线、事件驱动的适应机制
（BCM + IP），不依赖 BPTT/梯度训练——与 orz 机械层「零反传、确定性、可重放」约束
在结构上兼容。AGI 语境下 β/θ 的梯度训练路径（nn.Parameter + surrogate）不移植。**

## 2. 与 orz 现行 LIF 基座的逐项翻译对照

| # | orz 现行（MECHANICAL_LAYER_MATH_CALCULUS） | LIF3D | 翻译判定 |
|---|---|---|---|
| 1 | 时间基：事件驱动连续时间，`u(t)=u(t₀)·exp(−Δt/τ)+w` | 离散时间步 dt=1，`V[t]=β·V[t−1]+I` | **可无缝映射**：β^Δt ≡ exp(−Δt/τ)（β=e^(−1/τ)），事件驱动精确更新保留，τ=−1/ln(β) 互换；Δt 为事件间隔真实秒/轮数 |
| 2 | 通道结构：标量单态（一阶漏积分）+ 阈值 + 复位 + 不应期 | 三态 V/A/θ_eff + subtract reset + 动态阈值 | **结构升级**：A（适应）与 θ_eff（阈值抬升）联合取代现行"full-reset + 固定不应期"—— firing 语义实质变化，通道契约（§4.3 复位语义、LTL 验证）须重写 |
| 3 | 二阶 stuck 通道：两阶级联闭式解 | 无对应（3D 结构自身产生慢时间尺度适应） | **待裁决**：保留闭式并存，或由 3D 的 A 态吸收（§5-③） |
| 4 | 输入：标量事件（错误/拒绝/成功置 1 等），w 语义常数 | 输入：fc 线性投影（**训练权重**）+ β_mod-A（**训练投影**） | **不移植**：orz 无梯度训练；通道输入保持手工事件源；β_mod-C 可用手工信号（如事件密度）替代，v1 建议整体关闭 β_mod |
| 5 | 参数纪律：τ/θ/w 语义常数，版本级拟合禁止，仅 τ 秒值经 T̂ 换算 | β_raw/δ/g/θ_base 为 nn.Parameter（梯度训练）+ 塑性在线适应 | **需 ADR 级修订**：改为「β 锚点初始值语义推导 + 有界偏移 + 塑性 η/targets 语义推导」；梯度训练路径继续禁止；数据导出常数须带出处标注 |
| 6 | fires：内部留痕，无注入面（§4.6） | spk 为模块输出 | 判定不变：orz 侧 spk≡fires，仍无注入面 |
| 7 | T̂ 估计器（有界中位数） | 无对应 | **不受影响**：T̂ 非 LIF 通道；Part A（P1 轮次预算换算）完全独立于本替换，不被阻塞 |
| 8 | 四对照门 C1–C4 + 102-run 回放（ODE 参考偏差 0.006） | AGI 侧验证为训练任务 corr 指标 | **全量重验**：基座更换后全部特征值变化——旧 run grandfather、102-run 重放重算、C1–C4 重跑、判官 fixture 同步 |

## 3. 移植资格判定（对投影设计稿 §6.4-b 可重放资格线的回应）

- **确定性 ✓**：核心动力学为事件驱动确定性递推（β^Δt 精确更新，无 ODE 步长伪迹——
  与现行「右端点离散化 7–21× 伪迹禁止」结论兼容，exp-Euler 子步在 AGI 侧已证 bit-exact 复合）。
- **塑性确定性 ✓**：BCM/IP 为 EMA + 加性更新、零梯度；全部状态（V/A/spike_accum/
  running_* / β_raw / θ_base）可序列化入会话侧车，重放可精确。
- **学习组件 ✗ 已剔除**：fc、β_mod-A 投影不移植（orz 无训练回路）。
- **结论：LIF3D 通过可重放资格线**；代价是通道契约重写与全量重验（§2-#8）。

## 4. 诚实警示（来自 AGI 项目自身结论，须随移植入档）

`KNOWLEDGE_TRANSFER.md` 排行榜结论：**在 Lotka-Volterra 预测任务上，LIF 时序动力学对
性能无特异贡献**（Null-4 LN+ReLU 0.9950 ≈ Interleaved SSM-LIF 0.9958，「SSM 编码器才是

覆盖 orz 监控语境，但它把举证责任放在移植侧：**3D 结构相对 1D 基线在 orz 的监控职责上
必须有可测差异**——C1–C4 证伪门 + 域可分辨度读数正是为此存在；若 V2 复验不能显示
3D 优于 1D 退化路径，应按 AGI 同款诚实降回 1D（β-锚点设计恰好使 1D↔3D 为精确退化
关系，降级零成本）。

### 7.2 观测三判据（预注册，先于任何数据查看冻结）

观测目标（用户 2026-09-16 定向）：orz 实际动作中 LIF 是否出现**明显的、可用于判断的
分化特征**。操作化为三个递进判据：

| # | 判据 | 定义 | 通过标准（预注册值） |
|---|---|---|---|
| Q1 | 分离 | 3D 影子特征（主特征集见 §7.3）在事件 episode（journal 导出标签：错误爆发段／长工具段／墙钟耗尽／`run_invalidated`）与正常段的分布分离 | held-out episode 上 ≥1 个主特征 **AUC ≥ 0.70**（0.5＝机会水平；0.70 为可阈值化判据的最低有用分离度） |
| Q2 | 增量 | 3D 相对现行机制的**信息增量**。零假设＝AGI 结论的 orz 复现：「3D 特征只是 1D 的重编码」 | 最简判别器（logistic readout）对比：3D 对 **[1D＋闭式二阶]** 的 **ΔAUC ≥ 0.05** 且 run 级 bootstrap **95%CI 下界 > 0**（对照组含闭式通道，因 A 态与其功能重叠） |
| Q3 | 及时 | 分化达 Q1 阈值的时刻相对干预决策点（Pressure 域进入／err fire）的前置量 | **lead time ≥ 3 轮**（orientation 问询约 1 轮生效、自动后台化即时——3 轮为最小可用干预窗；此判据同时反推 P2/P3 的 horizon） |

### 7.3 统计纪律

- **run 为独立样本单位**（leave-one-run-out 或 run 级 bootstrap）；禁逐轮重采样（轮间强
  自相关）。
- **主特征集预注册**＝err 通道（V／A／θ_eff／spike 率）＋prog 通道（V／A）；其余特征只作
  探索性报告，不进入判据计数（防选择性呈现）。
- 全部读数（含负结果）如实入档；**Q2 判负即按 §4 承诺降回 1D**（β-锚点设计使 1D↔3D
  为精确退化关系，降级零成本）。
