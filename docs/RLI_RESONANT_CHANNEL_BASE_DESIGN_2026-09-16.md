## 1. 推导输入（orz 的七条硬约束）

1. **事件驱动精确更新**：事件间隔 Δt 不均匀（秒到分钟），禁止固定步长离散（步长伪迹）；
2. **确定性可重放**：给定事件流，任意历史时刻状态精确可复算；状态可序列化入侧车；
3. **O(1)/事件、有界内存**；
4. **在线自适应但零梯度**：无反向传播、无训练回路，适应机制必须是事件驱动的确定性更新；
5. **双尺度语义**：速率型通道固定墙钟尺度；新鲜度型通道以 T̂（在线节奏估计）归一；
6. **锚点丰富性**：每通道需提供水平之外的独立观测量——**恶化速率、收敛确认、节律异常**
   三种领先性语义（agent 病理的三种基本形态：持续恶化／已收敛／周期性打转）；
7. **可证伪**：所有"锚点有用"的主张必须能被对照门检验。

约束 6 是本推导的核心出发点：**实极点级联系统（一阶漏积分及其任意级联）的脉冲响应单调
衰减，数学上只能滞后**——变化率、收敛、节律三种语义住不住在实极点族里，必须引入
**复极点（欠阻尼谐振）**。

## 2. 通道定义与自由演化精确解

每通道二维状态 `(u, v)`：u＝电位（压力/新鲜度水平），v＝电位变化率。事件间隔 Δt 内
满足二阶线性系统（阻尼谐振子）：

```text
u″ + 2ζω·u′ + ω²·u = 0
ω_d = ω·√(1−ζ²)          （欠阻尼 0 < ζ < 1 时为阻尼振荡角频率）
ζ ∈ [0.05, 0.95]          （预注册区间；语义推导见 §6）
```

事件到达时以**闭式精确解**推进（无步长、O(1)、逐事件一次三角函数计算）：

```text
A = u₀；B = (v₀ + ζω·u₀)/ω_d
φ = e^(−ζω·Δt)；C = cos(ω_d·Δt)；S = sin(ω_d·Δt)
u₁ = φ·(A·C + B·S)
v₁ = φ·((ω_d·B − ζω·A)·C − (ω_d·A + ζω·B)·S)
事件注入：u₁ ← u₁ + w            （冲击语义在 u 上；v 不踢）
```

**双尺度**：速率型通道（err/stall/slow/deny）ω 取固定墙钟值（检测窗语义）；新鲜度型
通道（prog/stuck）ω = 2π/(k·T̂)，k 为语义常数——周期随 agent 自身节奏伸缩，与现行
τ = k·T̂ 的双尺度纪律同构。

## 3. 监测锚点（每通道四个，全部 O(1) 解析量）

| 锚点 | 定义 | 监控语义 |
|---|---|---|
| a1 | u | 水平（压力/新鲜度；承继现行语义） |
| a2 | v（及短视预测 û(t+T̂) ≈ u + v·T̂） | **预期锚点**：v > 0＝正在恶化；lead time 的直接来源 |
| a3 | 解析包络 E = φ·√(A² + B²)（单调衰减） | **收敛确认**：E 跌破阈＝episode ring-down——干预停手时机的锚 |
| a4 | 节律计数 r：事件间隔近似半周期（\|Δt − k·π/ω_d\| ≤ π/(4ω_d)，k=1,2,…）时 r ← r·e^(−Δt/τ_r) + 1，否则仅衰减 | **节律异常**：周期性重试/打转检测——实极点族结构性不可表达 |

## 4. 在线自适应：分位数自校准阈值（log 空间乘性更新，零梯度）

```text
u ≥ θ(t)：θ ← θ·e^(+η)
u < θ(t)：θ ← θ·e^(−η·(1−q)/q)         （期望更新平衡：E[Δlogθ]=0 当 P(u≥θ)=1−q）
q = 0.95（语义常数，"仅对本通道异常的 5% 时刻过阈"）
```

数学来源＝**稳健在线分位数估计**（乘性权重量化追踪）：θ 自动追踪 u 分布的 (1−q)
分位数，使过阈率对输入 regime 自归一——fires 含义跨负载可比（"对本通道异常"而非
"绝对幅度大"）。这是 RLI 唯一的参数适应机制：无速率目标项、无方差目标项、无梯度。

## 5. 复位语义（简化裁决）

**无复位、状态连续**：过阈（fire）为纯观测事件＋θ 自校准更新，不清空 u/v。
理由：a3/a4 锚点要求状态跨事件连续（清空破坏包络与节律检测）；现行
full-reset＋不应期机制及其 LTL 验证面随之退役（翻转批执行）。

## 6. 退化路径（包含现行基座）与参数语义初值

- **过阻尼极限**：ζ → 强过阻尼时快极点迅速衰减，慢模态 ≈ 一阶漏积分
  τ_slow = 1/(ω(ζ−√(ζ²−1)))——现行一阶基座是 RLI 的过阻尼极限（近似包含，差异由 C4 量化）；
- **无阻尼特例**：ζ = 0 → 纯振荡（证伪门 C3 的"阻尼=0"对照）。

参数初值（语义推导、非拟合；影子批复核后定稿）：

| 通道 | ω（周期语义） | ζ 初值 | w | q | η |
|---|---|---|---|---|---|
| err | 2π/180 s（承继现行 τ_err 窗） | 0.5 | 1/事件 | 0.95 | 影子批定 |
| stall | 2π/90 s（事件间隔看门狗窗） | 0.5 | 1/事件 | 0.95 | 同上 |
| slow | 2π/600 s（长工具窗） | 0.5 | min(5, wall_ms/60s)/事件 | 0.95 | 同上 |
| deny | 2π/120 s | 0.5 | 1/事件 | 0.95 | 同上 |
| prog | 2π/(8·T̂)（轮语义） | 0.5 | 成功置 1 | 0.95 | 同上 |
| stuck | 2π/(3·T̂)（轮语义） | 0.5 | 语义推导，影子批定 | 0.95 | 同上 |

ζ 语义区间 [0.3, 0.6]（足够过冲提供预期性，不至振铃拖尾）；初值 0.5（临界与欠阻尼的
中点，语义推导"预期性与稳定性的对称点"）。

## 8. 确定性契约

逐事件固定计算次序（φ、C、S 各算一次）；状态存储定点化（3 位小数，与 DynCtx 舍入
契约一致）；重放＝同一代码路径逐字段 bit-exact。跨平台三角函数一致性在 S2 定稿
（固定 libm 版本或整数毫厘定点实现，二选一，留设计裁决）。

## 9. 与 Part A/B 的耦合

- Part A（T̂ 轮次预算换算）不受影响（T̂ 为独立估计器）；
- Part B（Dyn 盖章）字段面按 RLI 特征重定：`DynCtx = {ch, u, v, E, r, θ}`（域闭枚举沿用）；
- 域状态机谓词框架不变，特征集换 RLI 锚点；谓词重推导随影子批设计稿。

## 11. 家族定位与理论复用面（2026-09-16 用户裁决）

- **属**：泄漏线性阈值事件系统（leaky linear-threshold event systems）——线性状态空间
  滤波 ＋ 事件冲量注入 ＋ 阈值跨越输出 ＋ 稳态自适应。现行一阶 LIF 基座与 RLI 同属此族
  （RLI 经强过阻尼极限包含一阶基座，§6）。
- **种差轴＝极点配置 → 监控语义映射**（族内可复用的设计理论）：

  | 极点配置 | 监控语义 | 实例 |
  |---|---|---|
  | 实轴慢极点 | 持久/记忆/适应 | 适应电流类状态、prog 新鲜度 |
  | 实轴快极点 | 瞬态爆发检测 | 错误压力通道 |
  | 复极点对 | 预期（速度超前）＋节律选择性 | RLI（u,v） |

  给定监控语义需求 → 查表定 ω/ζ/时标——极点配置表在族内双向通用。
- **双向理论复用面**：泄漏积分时标理论、阈值事件抽象、传递函数/稳态增益分析、
  双尺度归一（墙钟 vs T̂）、稳态自适应原则（目标统计量自归一——速率/方差/分位数目标
  为同族实例）、C1–C5 证伪门方法学。**不迁移面**：具体更新表达式、参数化方案、拟合参数。
- **法律边界**：族属是科学分类，不构成专利或公开意义上的关联；权利与披露只看具体
  表达式与权利要求。本设计的独立性（§首部）指推导与表达式独立，不指族属隔离。
